# Archived prototypes — excluded from builds

The root files are the previous A5A5/PING/PONG experiment, incompatible with
KymoStudio v6. The STM32 files are earlier incomplete CubeMX templates with
missing generated headers and empty peripheral initialization. They are kept
only to preserve the pre-existing work. Use the active root application and
`lib/KymoCore`, not these sources.
